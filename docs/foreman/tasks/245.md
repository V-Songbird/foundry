title: Task-adjacent lesson lines may enter a handoff, and are not the never-listed knowledge base
date: 2026-08-18
---

## Decision
`../../../foreman/docs/adr/SCOPE.md`'s "Only the selected task's detailed notes should enter a handoff"
becomes "Only the selected task's detailed notes should enter a handoff — plus
capped, staleness-labeled lesson lines from closed tasks whose observed files
intersect the task's planned files."

That is the whole charter change. It admits exactly one new class of text into
a handoff, and it admits it on four standing conditions, each already enforced
in code rather than asserted here:

- **Served only on planned-file intersection.** `touchesOverlap(planned_touches,
  record.paths)` is the entire selection rule. `area` is a cosmetic grouping key
  and nothing load-bearing reads it — the P0 probe measured that two thirds of
  this repo's closed entries have no dominant area at all.
- **Bounded.** At most six records, under a 1000-character ceiling covering the
  header and closer, enforced by whole-record drops. The block is age-flat: it
  costs the same on a project with four hundred closed tasks as on one with
  four.
- **Staleness-declared.** Every served line carries a fresh / possibly-stale /
  unknown verdict resolved against git at serving time. Every way of failing to
  resolve it lands on unknown; "unchanged" is a claim git has to earn. A record
  whose every file is gone is dropped rather than labelled.
- **Opt-in.** `areaNotes.enabled` defaults to false. Disabled is a total no-op:
  no writes, no quotes, no git calls.

## Context
`../../../foreman/docs/adr/SCOPE.md`'s "Project memory, not a knowledge database" section drew its line at
the selected task's own notes. The lesson ledger crosses that line, so the
charter had to move before the feature could honestly ship — the alternative was
a feature that quietly contradicted the document it is governed by.

What justifies the move is that the crossed line was drawn against a different
thing. The never-list bars a knowledge database: a taxonomy, a search service, a
browsable map, a knowledge graph. A lesson line is none of those. It is not
browsable, not searchable, not classified, and not reachable except by planning
to touch the file it already concerns. It is task-adjacent project memory —
closer to a task's own notes than to a wiki, and it reaches a session through
the same channel the task's notes already do.

Two adjacent things stay cut, and this decision does not reopen either:
co-change blast-radius statistics, and any prose describing "what an area does".
Both were rejected on measured grounds — the second is a platitude vector, and
neither carries a reliability payoff.

## Alternatives rejected
- **Leave `../../../foreman/docs/adr/SCOPE.md` alone and ship anyway.** The charter would say one thing
  and the code another, and the next audit would have to decide which was
  authoritative. A charter nobody can trust is worse than a narrow charter.
- **Amend the never-list instead.** The never-list bars a knowledge base, and a
  lesson line is not one. Weakening that entry would license the taxonomy and
  the search surface that the entry exists to bar.
- **Serve lessons from the task's own notes rather than a store.** Notes are
  per-entry, so a lesson recorded on entry 130 is invisible to entry 240 unless
  240 happens to recall 130 — which is the prior-work channel, and it is capped
  at three leads by reach, not by relevance to the file being edited.
- **Ship the store but never serve it in a handoff.** Then the charter needs no
  amendment and the feature has no read side. Write-only project memory is the
  cost with none of the payoff.

## Consequences
- The measured claim behind the feature — that a labelled lesson helps and an
  unlabelled stale one harms — is still unmeasured. Entry 246 builds the P2/P3
  harness and stops for a batch approval; nothing past it ships on assumption.
- If P2 shows graded-stale poisons haiku, the fallback is anchors-only for
  possibly-stale. That changes what a line says, not whether the charter
  permits it, so this decision stands either way.
- If P4 counts near-zero destination references to quoted lessons, every
  constant freezes and stage 2 is never built. The amendment still describes
  what shipped.
