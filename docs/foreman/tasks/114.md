**Superseded 2026-08-01 (entry 146, foreman 1.0 close):** the raise-the-session question and its fresh-session option were deleted; the drift pins named in Consequences no longer exist. Historical only.

## Decision
The raise-the-session question (`Call 5c` in craft-prompt, `Q4` in the roadmap skill)
keeps its two-option shape, but the second option is now `Start it in a fresh session`:
the prompt is delivered exactly as the `Copy prompt to clipboard` destination delivers
it, and nothing runs in this session — no task row, no execution. Switching this
session's model or effort in place is deliberately absent from the list. Everything else
entry 111 established is unchanged: once per handoff, before the first task row, never a
gate, never records anything, never written into the assembled prompt.

## Context
Entry 111 shipped `I'll switch first` as the acting-on-it option. Changing either the
model or the reasoning effort mid-conversation invalidates the prompt cache, so every
remaining turn re-reads the whole history — the option that was supposed to be the cheap
correction is the expensive one, and it gets more expensive the longer the session has
run. A fresh session pays the same cost once, at the shortest history it will ever have.

## Alternatives rejected
- Keeping `I'll switch first` as a third option — it is the trap the entry exists to
  remove; leaving it on the list is leaving it as a choice.
- Recommending a background `Agent` instead — the `Agent` call takes a `model` but no
  effort argument, so it closes the model half and leaves the effort half open. A
  per-agent `effort:` frontmatter pin in an `agents/*.md` definition can set it, but that
  requires a pre-existing agent file per model/effort pair, which is not a general answer.
- Measuring the cache cost before deciding — the invalidation is a property of the
  request key, not a probabilistic effect; there is nothing to measure.

## Consequences
`Execute here` now has an exit that leaves the destination unchanged from Foreman's
side — the fresh-session branch is the clipboard path under a different label, so it
inherits the clipboard path's behavior exactly, including the absence of
`task-created.js` and `task-completed.js`. Drift pins in `check_prompt.test.js` hold the
cache reason, the `Agent`-has-no-effort reason, the fresh-session option, its clipboard
delivery rule, and the absence of the old `I'll switch first` string, across all three
files. If the `Agent` tool ever gains an effort argument, the rejected alternative above
becomes viable and this entry should be revisited.
