## Decision
The "What you can do" command table in hush/README.md keeps its `/hush:pick-style`
and `/hush:craft-style` rows even though those commands now have their own
feature section ("Make it sound like you"). The table is the complete command
index; the feature section is the pitch. The two serve different jobs.

## Context
Promoting the style-building pitch into the single feature slot (entry 098)
left the same two commands named in both the command table and the new section.
The template's feature-slot note says a feature needing its own pitch "gets the
single slot below instead", which can be read as "drop the table row".

## Alternatives rejected
- Drop the two rows from the command table — reading "instead" as remove-the-row
  leaves the command quick-reference incomplete; a user scanning for "how do I
  switch styles" should still find it in the index, not only in prose.

## Consequences
Every user-facing command stays listed in the one command table, and the feature
slot stays a pitch rather than a second index. Future feature-slot promotions in
this repo should follow the same split: promote the pitch, keep the command row.
