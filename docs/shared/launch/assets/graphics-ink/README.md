# Ink graphics

Nine Hush, Foreman and Razor graphics restyled from retained sources. Run `node docs/shared/launch/assets/graphics-ink/build.cjs` to regenerate the output and validation.json. This command does not install or publish assets.

Hand-drawn frames and label containers, flat white/charcoal surfaces, no drop shadows. Plotted marks, bar dimensions, text and replay animation nodes are preserved. Semantic success/error colors are not brand accents. Existing banners and logos remain unchanged.

Outputs are copied to all existing local edition and main-page worktrees that already contain the corresponding asset. Pair and navigation checks passed.
