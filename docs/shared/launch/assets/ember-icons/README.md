# Ember-style icons

Candidate light/dark SVG icons based on the existing Hush curves, Foreman ribbon and Razor blade. Flat fills, rounded ink outlines, no shine or brush texture. Identical geometry across themes. Published icons and banners remain unchanged pending visual selection.

Revision: Hush uses an explicit shh speech bubble; Flint adds two stones and a spark. Brand fills remain identical between light and dark, with theme-specific ink outlines only.

Foundry adds a rounded pouring crucible and warm drop, in the same flat ink style. Its colors remain identical across themes.
